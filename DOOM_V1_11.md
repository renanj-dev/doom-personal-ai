# Doom v1.11.0 — Knowledge Management

A Base de Conhecimento recebeu uma camada de gestão avançada.

## Recursos
- filtros por coleção, tópico e tipo de fonte;
- catálogo e estatísticas da base;
- reindexação manual por documento;
- endpoint de detalhe com conteúdo completo para edição;
- UI sincronizada em `v1.11.0`;
- preservação da separação entre Memory Engine e Knowledge Engine.

## Interface
O indicador da interface, cache-busting do JavaScript e versão de saúde do Core foram atualizados para `v1.11.0`.
